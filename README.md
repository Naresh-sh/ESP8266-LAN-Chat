⚔️ NodeX LAN Chat (ESP8266)

NodeX LAN Chat is a real-time local network messenger built using ESP8266.
It creates its own WiFi hotspot and allows multiple devices to chat without internet 📡

✨ REATURES-------------------------------------------------------------------------------------------------------------------------------------------------------------------------

💬 Realtime Chat
Instant messaging using WebSockets (no refresh required)

👥 Group + Private Chat
Talk with everyone or chat one-to-one

😀 Emoji Support
Built-in emoji picker with search

👍 Message Reactions
React using 👍 😂 😮 😢 🔥 💯 😈

🗑 Delete Message
Delete your messages for everyone

⌨️ Typing Indicator
See when someone is typing...

📜 Auto Message History
Restores last 45 sec messages when new user joins

👻 Ghost Mode (Secret Feature)
Send anonymous messages

🔊 Sound Effects
Audio feedback for send, receive, join, delete

🎨 Modern UI
Dark futuristic design with smooth animations

🧰 Hardware Required----------------------------------------------------------------------------------------------------------------------------------------------------------------
ESP8266 (NodeMCU / ESP-12E)
USB cable
Laptop or Mobile browser


💻 Software Required----------------------------------------------------------------------------------------------------------------------------------------------------------------

Arduino IDE + libraries:

ESP8266WiFi
ESP8266WebServer
WebSocketsServer
ArduinoJson
